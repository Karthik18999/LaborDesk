# Labor Desk - Workforce Management Platform

Labor Desk is a production-ready enterprise workforce management platform connecting corporate infrastructure builders with physically registered, verified blue-collar workers.

## Features
- **Central Admin Operations Portal**: Physical worker registration, Aadhaar verification, company approval, worker matching engine, daily attendance logs, printable PDF invoices, and analytics.
- **Corporate Client Portal**: Worker requirement submission, active request workflow stepper, assigned worker roster, and invoice downloads.
- **Landing Page**: Modern corporate design with dark/light mode toggle, dynamic industry rosters, FAQs, and contact information.
